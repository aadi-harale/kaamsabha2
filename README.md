# KaamSabha2

Active SIH26089 implementation: a cooperative household/community services platform where workers collectively own the marketplace rules that decide access to work.

This repository is the writable implementation workspace. `aadi-harale/KaamSabha` is reference-only.

## Current foundation
- Native Next.js 16 / React 19 runtime for Vercel.
- Customer / worker / admin session isolation.
- Versioned deterministic demo repository and guarded state transitions.
- Worker Protection Floor, deterministic eligibility, frozen Decision Receipts and governance primitives.
- Vercel health route and environment boundary documentation.

Run locally with `npm install && npm run dev`. Verification is `npm run verify`.

See `AGENTS.md`, `AGENT_STATE.md`, and `VERCEL_DEPLOY.md` before modifying the application.
